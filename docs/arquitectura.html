Mapa de fuentes de datos

Qué se descarga, qué se transforma y qué termina realmente en la experiencia.

Respuesta corta

La app no scrapea Facilito. El precio viene de un CSV descargable de Osinergmin; Registro y GIS completan establecimiento y coordenada; un PDF first-party alimenta el piloto privado de identidad. El navegador consume después un endpoint local derivado: /api/dataset.

Activa HTTP · CSV 1.05 GB

Osinergmin SCOP · Líquidos vigentes

Descarga directa, no endpoint JSON. Aporta precio, fecha, producto, unidad, territorio y REGISTRO. Precios activos: 18/08/2026. Un HEAD detecta cambios con 0 bytes; si cambian los validadores, el CSV se verifica, minimiza y promueve mediante staging.

Activa HTML tabular Proveniencia legacy

Registro de Hidrocarburos · Osinergmin

Exportaciones por actividad guardadas como .xls.html. Aportan autorización, razón social y dirección para el join exacto. Snapshot minimizado: 17,742 autorizaciones; originales privados y permiso de publicación aún ambiguo.

Activa ArcGIS REST · GeoJSON No publicable hoy

Servicio GIS · Osinergmin

Consultas paginadas a capas oficiales; el producto usa la capa 35 mediante REGISTRO ↔ N. Aporta coordenadas y control territorial. El servicio muestra copyright, pero no una licencia explícita; la adquisición original tiene proveniencia legacy.

Preview privado PDF first-party Stale · permiso unknown

Repsol You · relación de estaciones

PDF corporativo usado para vincular dirección exacta con nombre público de sede. Resultado: 11/14 candidatos verificados; 3 sin match. Vive como overlay separado y ninguna entrada es publicable hoy.

Lo que sigue

Capa 3 está cerrada. Los siguientes gates son hipótesis de Capa 4; el stack productivo sigue abierto.

Siguiente · Gate 4.1

Convertir el slice en PWA

  • HipótesisEl contrato estable permite una experiencia instalable mobile-first sin backend nuevo.
  • TangiblePWA candidate con shell offline y corte de datos visible.
  • SalidaFlujo principal instalable y recuperable en móvil.
Posterior · Gate 4.2

Resolver el boundary público

  • HipótesisUna estrategia explícita de ubicación puede volver útil el modo público sin fabricar permisos.
  • TangibleFuente sustituida, permiso demostrado o experiencia pública honesta sin coordenadas.
  • SalidaBoundary public_safe útil y medido.
Tentativo · Gate 4.3

Publicar y medir utilidad

  • HipótesisUna versión estrecha puede ayudar sin ocultar procedencia ni incertidumbre.
  • TangibleRelease público reversible con medición mínima y privacidad revisada.
  • SalidaUso real suficiente para decidir qué conservar, corregir o eliminar.

Área gris documentada, no bloqueo

La coordenada GIS no tiene licencia explícita demostrada y la identidad comercial sigue con publicación desconocida. Esto no bloquea Gate 4.1 privado, pero sí debe resolverse o diseñarse explícitamente antes de una versión pública útil. No se afirma stock, descuento ni nombre comercial inferido.
